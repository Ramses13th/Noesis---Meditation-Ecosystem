# Noesis · Meditation Ecosystem

Noesis is an independent, English-language practice companion inspired by Temple of Zeus. Open the Atlas and tap Dot Meditation to prepare your session. Practice time, reflections, mastery marks, rank and weekly goals stay in your browser.

## GitHub Pages

Publish the repository using Settings → Pages → Deploy from a branch → main → /(root). Open the published HTTPS address on your phone and tap Install, or use Safari → Share → Add to Home Screen. After the first online load, the app works offline. External source pages require a connection.

## Rites

Rites shows the seasonal Cure and Banish using the recurring festival dates in the [Temple calendar](https://templeofzeus.org/holidays) and the [official seasonal assignments](https://templeofzeus.org/doctrines-declarationonritualschedulesandcommunityleadership). The date changes with the device’s local calendar. The forum link leads to the schedule announcement.

The Apollon counter follows the order and counts in the [official ritual](https://tozrituals.org/rituals/god/apollo-azazel-power-ritual). Tap the sigil after each repetition. Your place is saved. A completed observance earns a dated journal seal.

The public edition links to the full official prayers. A personal edition can read privately saved source HTML automatically. Original texts and offline copies of the official sigil are excluded from the public repository.

## Transfer

In Progress or Journal, use Transfer code, copy the code on the old device, paste on the new one, and choose Restore code. The code contains the journal and grows with it. JSON backups from earlier releases are supported. Restore merges entries by ID, keeps the most recently edited reflection, and restores settings and ritual position.
